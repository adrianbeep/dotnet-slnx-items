# dotnet-slnx-items — Docs

Documentation for the project lives here.

## Structure

- **`/docs/adr/`** — Architecture Decision Records. Decisions we made and why.
- **`/docs/design/`** — Design artifacts (schemas, MVP scope, etc.) written as separate docs when they need more room than an ADR allows.

See `/docs/adr/README.md` for how to write an ADR.
